Geliştirme alanın

İhtiyacın olan her şey.
Tek bir akışta.

Fikirden çalışan Python koduna kadar, günlük geliştirme araçlarını sade ve odaklı bir arayüzde buluştur.

⌘

Akıllı kod editörü

Python renklendirme, satır numaraları, otomatik girinti ve sekmelerle kodunu düzenli tut.

▶

Gerçek Python Runner

Kodunu ayrı Python sürecinde başlat, çalışmayı durdur ve gerçek program çıktısını gör.

▤

Entegre terminal

Program çıktısı ve hata mesajlarını aynı çalışma alanında takip et.

⌕

Proje gezgini

Dosyalarını aç, kaydet ve Python proje klasöründe rahatça gezin.

◉

Hata ayıklama

Breakpoint desteğiyle kod akışını incele ve sorunları daha hızlı bul.

＋

Python paketleri

pip paketlerini yönet, otomatik tamamlama ile kod yazarken önerilerden yararlan.
